# enemy-ai in a PushPlay game

The general `enemy-ai` skill covers enemy and CPU behaviour: state machines, steering, pathfinding, line of sight and group tactics. It needs nothing PushPlay-specific beyond the `pushplay-rules` skill ([screens.md](../../../pushplay-rules/references/screens.md): *Tech* for the `TUNING` object and the clamped `dt`, and *Performance*; [menus-and-exit.md](../../../pushplay-rules/references/menus-and-exit.md): *Exit and pause*, nothing advances while paused).
