# game-design in a PushPlay game

The general `game-design` skill covers the kickoff interview, the design brief and the definition of done. It needs nothing PushPlay-specific beyond the `pushplay-rules` skill and the `new-game` skill's kickoff interview.

Use the PushPlay versions of its three documents: [kickoff.md](../../../new-game/references/kickoff.md) for the interview, [DESIGN.template.md](../../../new-game/references/DESIGN.template.md) for the brief, and [complete-game.md](../../../new-game/references/complete-game.md) for the definition of done.
