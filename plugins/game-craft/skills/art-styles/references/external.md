# Other people's skills for one style

Skills that go deeper on a single style than a sheet here can. They are optional. Mention a fitting one to the
user once; install nothing without their yes, and read a skill before recommending it for a project, because it
may assume an engine or add files the project's rules do not allow.

A skill is listed only if it is public, states an open licence, needs no paid key (or says so), and teaches
technique instead of copying one game's art. Licences are as each repository stated them when it was added:
check again before copying anything out of one.

| Style | Skill | Licence | What it adds | Assumes |
|---|---|---|---|---|
| Papercraft | [xikhar/papercraft](https://github.com/xikhar/papercraft) | MIT | Full pop-up dioramas: slotted and folded structures, printed collage textures, hinge motion, paper sounds, a three.js kit | a browser; three.js, canvas or SVG; Python for its capture scripts |
| Pixel art | [with-pebbly/aseprite-ai-artist](https://github.com/with-pebbly/aseprite-ai-artist) | MIT | About 80 rule files with grid templates: characters, small creatures, eyes, trees and foliage, architecture, outlines | Aseprite for its tooling; the rules hold in any pixel editor |
| Pixel art | [crsolver/claude-pxl](https://github.com/crsolver/claude-pxl) | MIT | A small JavaScript language for pixel art: mirror symmetric halves, auto-outline, "no filler noise" | JavaScript |
| Vector illustration | [MengTo/Skills](https://github.com/MengTo/Skills) (`agent-skills/illustration`) | MIT | Fourteen illustration styles with measured stroke widths, plus a shared craft file on hands, pose and contact | SVG |
| Comic, ink wash | [illodev/drawn-by-code](https://github.com/illodev/drawn-by-code) (`.claude/skills`) | MIT | Swelling ink lines, graded halftone, union-of-circles outlines, procedural ink-wash trees | canvas 2D |
| Toon / cel | [xymeow/three-anime-style](https://github.com/xymeow/three-anime-style) | MIT | An anime shading library with edge-detected outlines and stepped animation | three.js |
| Several 3D styles | [matinsizen/ai-3d-animator-skill](https://github.com/matinsizen/ai-3d-animator-skill) | MIT | Short recipes for low-poly, toon, claymation, voxel and retro looks | three.js |
| Voxel | [omer-metin/skills-for-antigravity](https://github.com/omer-metin/skills-for-antigravity) (`skills/voxel-art`) | Apache-2.0 | Palette-first workflow and proportions for 16 and 32 voxel characters | none |

No dedicated skill was found for claymation, watercolour or neon. Those sheets cite the write-ups and
open-source projects their rules came from.

To add a row: read the skill end to end, check its licence file, and confirm it meets the test above.
